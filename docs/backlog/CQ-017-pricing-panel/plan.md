## Why

The Pricing tab's top half is the "automate by default, edit by exception" moment: every pricing-relevant number is pre-filled from the pipeline (tax, insurance, HOA, rent/STR) with a visible source, computed once by `quote_engine`, and editable only where the LO actually disagrees. This item wires the missing `GET .../pricing` view, makes `/quotes/preview` accept either side of the down-payment % ⇄ $ link (server-side, per AGENTS.md's money-math rule), and makes an override/revert mark existing quotes stale so CQ-018's reprice flow has something to react to.
