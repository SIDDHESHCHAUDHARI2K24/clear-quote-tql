## E2E recipe (each worker runs this in its worktree)

1. Setup, once per worktree: `scripts/worktree-env.sh <slot>` (from foundation). Slot N gives DBs `cq_dev_s<N>`/`cq_test_s<N>`, Valkey db N+2, API port 8100+N, LO port 3100+N, portal port 3200+N, Temporal task queue `cq-s<N>`, plus both apps' `NEXT_PUBLIC_API_URL`. The shared infra from `make up` stays running; never touch the `cq_dev`, `cq_test` or `*_p2` DBs or ports 8000/8012. Slots: foundation=1, CQ-021=2, CQ-016=3, CQ-022=4, CQ-017=5, CQ-023=6, CQ-024=7, CQ-018=8, CQ-019=9, CQ-020=10.
2. `make demo-reset`, then start the API (`uv run uvicorn app.main:app --port $API_PORT`), the worker when needed (`make worker`), and the affected app(s) (`pnpm --filter @cq/<app> exec next dev -p <port>`), all in the background.
3. API: sign in as `lo@clearquote.test` (password from `.env` `SEED_STAFF_PASSWORD`, OTP read from the Mailpit API `http://localhost:8025/api/v1/messages`). curl the item's new endpoints for the AC personas and check the numbers.
4. UI: `make e2e` / `pnpm exec playwright test <item specs>` against the worktree ports. Save screenshots at the widths the ACs name to `docs/backlog/CQ-0XX-*/evidence/`.
5. Stop the background processes. CQ-021 uses only the gallery (no API). The foundation unit runs only the smoke specs.

## Orchestration steps

1. **Now (after approval):** the human runs `! brew install pango`. Poll `gh pr list --state merged` for the P2 PR. Do wave 0 when it has merged. Until then, only write `docs/backlog/phase-p3-p4-plan.md` and the spec edits in a local branch.
2. **Per wave:** move each item's Kaneo task to In Progress. Launch one Sonnet worker per unit (`model: "sonnet"`, `isolation: "worktree"`, background, all units of the wave in one message).
3. **When a worker reports a PR:** dispatch a fresh Sonnet reviewer on the PR diff against the spec (stage 6). Relay critical and major findings to the worker through SendMessage, then re-review.
4. **Merge:** `gh pr merge --merge` into `phase-p3-p4`. Resolve generated-file conflicts with `make api-client` (D5). Check that `alembic heads` = 1. Run `make lint && make test` on phase-p3-p4 in `.worktrees/phase-p3-p4` (slot 0 env). Push. Post a Kaneo comment and keep the task In Review.
5. **After wave 6:** re-verify the cross-item ACs end to end (CQ-022 AC1, CQ-024 AC1/AC6, CQ-019 AC2). Open the PR from `phase-p3-p4` to `main` for the human. Update memory.
